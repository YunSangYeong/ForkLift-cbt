## 출처와 확인 수준

- 원문 기출 0 / 복원 0 / 자체 제작 1,000. 연도와 회차는 모두 null.
- 개념 원고 `scripts/concepts.tsv` 100개는 AI 일반 지식에 의한 자체 작성이다. 읽지 않은 공식 교재나 제조사 설명서, KOSHA 문서를 정답 근거로 인용하지 않았다.
- 공식 Q-Net 종목정보는 시험 영역·시간·문항 수·형식·합격 요건 확인에 사용했다. 이 자료가 각 문제의 정답을 입증하는 것은 아니다.
- sourceUrl의 GitHub 링크는 작성·검토 위치이다. 외부 독립 문헌 증빙이 아니다.
- 공개된 민간 기출 페이지에서 무단 복제하지 않았다. 공식 필기 원문·회차·정답·재배포 조건이 모두 확보된 자료는 없어서 기출로 분류하지 않는다. 기출이 존재하지 않는다는 결론은 아니다.
- 내부 검수 완료(reviewed)는 아래 범위의 내부 확인이며 외부 전문가 승인·공식 출제기준 전수 적합성을 뜻하지 않는다.

## 개념 100개 검토

각 영역 20개. 운전 전 조향·제동 점검, 후륜 조향, 전도·시야·경사로, 팔레트·포크·총중량·하중중심, 통로·보행자·다리판·트럭, 랙·마스트·유압·협착·정비, 충전·연료·위험성·비상조치 등을 다룬다.

작성 과정에서 조건과 보기를 대조하고 하나의 적절한 답이 있도록 문장을 검토했다. 좌승식과 입승식의 전도 대응 차이, 납산과 리튬 배터리 차이, 하중중심 비례식이 실제 허용하중을 정하지 않는 점을 분리했다. 법령의 조문 번호·수치·벌칙·최신 개정 기준은 검증되지 않은 채 문제에 넣지 않았다. 자동 검사는 문장 의미 전체를 보증하지 않으며 외부 전문가의 개념·해설 검수는 받지 않았다.

주제별 비슷한 안전 원칙을 서로 다른 작업 단계에 다시 묻는 경우가 있다. 의미상 관련성은 유지했으며 완전히 독립된 지식 100개라고 주장하지 않는다. 단순한 동의어 치환으로 1,000개 개념을 만들지 않았다.

## 계산 30유형 × 30조건

- 주행: 속도 환산, 등속 거리, 이동시간, 경사도, 바퀴 회전 거리, 반응거리.
- 적재: 총중량, 상자당 중량, 질량·거리 모멘트 지표, 이상 등가 질량, 합성 중심, 확인된 한도 대비 비율.
- 운반: 사이클 시간, 시간당 운반량, 왕복거리, 평균속도, 연료량, 잔여시간.
- 하역: 압력, 실린더 힘, 체적, 유량과 시간, 인상 일, 평균동력.
- 안전관리: 이상 제동거리, 총정지거리, 운동에너지, 높이 차, 중앙 배치 폭 여유, 균등 평균 면적하중.

문제는 이상화 조건·정의·주어진 값과 단위를 명시한다. 값은 작은 순서의 결정적 조건 30개이며 실제 운행 권장값이 아니다. 계산은 소수 둘째 자리까지 일반 반올림하며 해설에 식·환산·대입·결과를 제공한다. kg·m 지표와 N·m 토크, kg/m²와 압력 Pa를 구분한다.

Python Decimal 생성 코드와 별개의 TypeScript 계산표로 900문항을 재계산한다. 면적·체적 환산은 별도 SI 경로를 사용한다. 모든 보기의 숫자를 읽어 동치 정답이 하나인지 확인하고, 정답 번호의 실제 보기와 결과·단위 대응을 확인한다. 계산값 테스트와 해설의 전문가 검수는 다르다.

## 수량·중복·재현

내부 검수 기본 1,000, 대기 0, 로컬 등록 제외. ID와 NFKC·공백 정규화 본문 및 정렬된 보기 fingerprint 중복을 검사한다. 동일 family의 조건 값 30조합은 서로 다르다. 생성 반복 시 JSON 바이트가 동일함을 테스트한다. 생성은 기본 JSON과 양식만 변경하며 다른 자료·학습 기록은 만지지 않는다.

개념 원고와 계산 유형은 관련성이 있고 같은 기본 공식을 다른 작업 조건에서 쓰기도 한다. 변형 900개를 기출 900개·독립 개념 900개로 해석해서는 안 된다. 90% 계산 조건 변형인 은행은 실제 시험 내용 비중과 다르다. 시험에서는 family 중복을 우선 피하지만 전체 내용의 시험 적합성 전수 대조는 남아 있다.
